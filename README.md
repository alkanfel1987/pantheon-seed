# Pantheon Seed — миниядро

**English:** [README.en.md](README.en.md)

Миниядро для Claude Code: двенадцать навыков работы с информацией и качеством, каркас памяти и правила сессии. Ты обучаешь его у себя, на своих задачах.

Язык навыков — русский.

## Зачем это

Один человек находит свои ошибки медленно: чтобы класс промаха стал заметен, он должен повториться несколько раз. Если миниядро обучают многие, каждый на своих задачах, общее ядро растёт от опыта всех сразу.

Цель проекта — **ядро, которое быстрее учится на опыте многих людей и отдаёт этот опыт обратно каждому**. Ты обучаешь своё миниядро. Навыки, которые у тебя заработали, проходят проверку и попадают в общее ядро. Оттуда они вместе с нашими доработками приходят ко всем пользователям очередным релизом.

```
  основное ядро ──── релиз ────▶ миниядро у каждого пользователя
        ▲                                   │
        │                        обучение на своих задачах
   карантин 7+1                             │
   слепая проверка                          ▼
   решение человека ◀── форма или форк ── навык, который заработал
```

## Цели проекта и что они дают тебе

У проекта три цели. Под каждую заложены функции, и из них складывается то, что получает человек.

### 1. Claude работает с информацией по проверяемым правилам

**Заложено:** навыки проверки источников, разделения измеренного и сказанного, слепой проверки своей разметки, карантина перед записью в память; карта методов, которая говорит, какой навык брать для какой задачи.

**Что это даёт:** ответы и выводы, у которых видно основание. Claude отличает первоисточник от пересказа, число от мнения, проверенное от предположения, а непроверенное не оседает в памяти как факт.

### 2. Claude учится на своих промахах — у тебя и у всех

**Заложено:** трейс каждой сессии с тегами ошибок и удачных приёмов; счётчик, который выносит класс, повторившийся трижды; навык `promote-pattern`, который превращает его в правку навыка, правило или новый навык.

**Что это даёт:** промах, повторившийся трижды, перестаёт быть привычкой и становится правкой. Твоё миниядро с каждой неделей работы точнее подстроено под твои задачи.

### 3. Опыт каждого возвращается ко всем

**Заложено:** мост с основным ядром — формы подачи и просмотр форков; карантин 7+1, слепая проверка и решение человека по каждому навыку; релизы; рутина, которая раз в день готовит обновление.

**Что это даёт:** навык, который заработал у кого-то одного, после проверки приходит к тебе следующим релизом. Твой собственный навык может разойтись по всем миниядрам, авторство остаётся в истории git.

### Что держится при всех трёх

- **Твоё остаётся твоим.** Память и трейсы лежат на твоём диске и в публичный форк не уходят. Наружу попадает только то, что ты сам закоммитил или отправил формой.
- **Ничего не ставится без тебя.** Рутина готовит обновление, ставишь его ты, одним «да».
- **Без сервера, без телеметрии, без оплаты нам.** Лицензия MIT.

## Как начать

Нужны [Claude Code](https://claude.com/claude-code), git и Python 3 (для скриптов слепой проверки и счётчика повторов).

1. Нажми **Fork** на этой странице (или `gh repo fork alkanfel1987/pantheon-seed --clone`, если стоит GitHub CLI).
2. Склонируй свой форк и подключи наш репозиторий как источник обновлений:

```bash
git clone https://github.com/<твой-логин>/pantheon-seed.git
cd pantheon-seed
git remote add upstream https://github.com/alkanfel1987/pantheon-seed.git
claude
```

Ставь и обновляй миниядро **только из `alkanfel1987/pantheon-seed`**: чужие форки мы не проверяем.

Сессии запускаются из этой папки: Claude Code сам подхватывает навыки из `.claude/skills/`, правила из `CLAUDE.md` и память из `memory/`. Устанавливать ничего не нужно. При первом запуске Claude Code спросит, доверять ли папке, — после «да» начнут действовать и разрешения из `.claude/settings.json`: без запроса идут только проверка (`routine.py run`) и отчёт (`routine.py report`), всё остальное Claude спрашивает.

### Работа со своими проектами

Миниядро действует там, где открыт Claude Code. Поэтому **открывай Claude Code в папке миниядра, а свой проект подключай вторым каталогом**:

```bash
cd pantheon-seed
claude --add-dir ../my-project
```

В приложении Claude — «добавить папку» к сессии. Так навыки, память и правила миниядра работают над твоим кодом.

### Свои правила и навыки

- **Правила** — в `memory/rules.md` (Claude создаст его в первой сессии). `CLAUDE.md` не правь: его обновляют релизы, и твоя правка заблокирует обновление.
- **Навыки** — под своим именем: `.claude/skills/my-…/`. Наши навыки лучше не править: если правил, рутина не обновит этот файл и скажет об этом.

## Рутина: проверка и обновления

```bash
python scripts/routine.py install
```

Раз в день (Windows — планировщик задач; Linux/macOS — строка для cron) рутина:

- проверяет целостность: навыки на месте, скрипты отвечают, ссылки целы;
- считает по локальным журналам Claude Code, какие навыки ты реально вызываешь, и сводит цикл обучения;
- смотрит, вышел ли новый **релиз** (не просто свежий `main`), и готовит его.

Всё пишется в `memory/routine-status.md`. В начале следующей сессии Claude расскажет, что нашлось, и спросит, ставить ли обновление. **Сама рутина ничего не ставит и ничего не отправляет.** Модель не вызывает и токенов не тратит.

**Свои навыки заводи под своим именем** (`.claude/skills/my-…`). Если ты правил наш навык, а релиз меняет тот же файл, рутина не обновит и назовёт файл. Правку лучше вернуть в ядро через [CONTRIBUTING.md](CONTRIBUTING.md).

Без рутины: `python scripts/routine.py run`, затем `python scripts/routine.py apply`. Если после обновления что-то сломалось — `python scripts/routine.py rollback` вернёт прежнее состояние (если после обновления ты ничего своего не коммитил).

Подписаться на релизы: на странице репозитория Watch → Custom → Releases.

**Поделиться, как работает миниядро:** `python scripts/routine.py report` печатает сводные числа (без путей и текстов). Их можно вставить в форму «Отчёт о работе» в [pantheon-seed-data](https://github.com/alkanfel1987/pantheon-seed-data). Отправляешь ты сам, рутина ничего не шлёт.

`docs/` — основания: карта методов, Прамана-пятёрка, карантинный фильтр 7+1. `memory/` — каркас памяти: указатель, образец трейса, соглашение о тегах. `scripts/` — слепая проверка, счётчик повторов, мост.

## Как миниядро учится

1. В каждой сессии ведётся трейс: ошибки и удачные приёмы записываются тегами (`memory/pattern-promotion.md`).
2. Класс, повторившийся трижды, `scripts/pattern_counter.py` выносит наверх.
3. Навык `promote-pattern` превращает его в правку: поправить навык, добавить правило в `CLAUDE.md` или завести новый навык в `.claude/skills/`.

## Что уходит наружу, а что нет

**Память и трейсы остаются у тебя** — они в `.gitignore` и в публичный форк не попадают. Делятся только навыки из `.claude/skills/`, и только если ты сам их закоммитил в форк.

## Как вклад попадает в ядро

Основное ядро раз в какое-то время просматривает форки (`scripts/bridge.py harvest`). Изменённые и новые навыки **не сливаются автоматически никогда**. Каждый уходит в карантин:

- испытание по уязвимости — что вклад может сделать на чужой машине: текст, код или хуки;
- фильтр 7+1 (`docs/quarantine.md`) и слепая проверка;
- решение человека по каждому навыку.

Хуки и настройки не принимаются вовсе. Подробнее — [CONTRIBUTING.md](CONTRIBUTING.md).
