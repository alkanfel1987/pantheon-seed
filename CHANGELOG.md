# Журнал изменений

## v0.5.0 — 2026-10-14

- **Каталог по сферам:** `catalog.json` — 12 сфер применения со смежными и синонимами для поиска; навыки размечены по сферам двумя независимыми разметками (основные сферы — где обе совпали, «также» — где одна).
- `python scripts/find.py <своя ситуация>` — навыки твоей сферы, потом смежных; `--en` — по-английски; `--md` — пересобрать `CATALOG.md` и `CATALOG.en.md` для ручного выбора.
- Claude сам переводит описание задачи в сферы и показывает навыки (правило в `CLAUDE.md`); поиск разрешён без запроса.
- Рутина проверяет, что каждый навык каталога на месте.
- Форма «Навык для ядра»: поле «Сферы применения».

## v0.4.1 — 2026-10-14

- README (русский и английский): какие боли решает миниядро, почему ему важно расти у тебя, почему навыки от людей работают лучше самообучения машины, как найти своё среди множества навыков.

## v0.4.0 — 2026-10-14

- **Работа со своими проектами:** миниядро — дом, проект подключается `claude --add-dir`; описано в README и `CLAUDE.md`.
- **Свои правила — в `memory/rules.md`**, подключены к `CLAUDE.md`; `promote-pattern` пишет туда. `CLAUDE.md` принадлежит релизам — своя правка в нём больше не блокирует обновление.
- **Откат:** `routine.py rollback` возвращает состояние до последнего `apply`, если после него не было своих коммитов и правок.
- **Первая сессия:** Claude коротко рассказывает, что умеет миниядро и с чего начать.
- **`.claude/settings.json`:** без запроса разрешения идут только `routine.py run` и `routine.py report`.
- **Куда писать:** Issues — форма «Ошибка»; Discussions — вопросы и идеи; уязвимости — закрыто, `SECURITY.md`; отчёты и навыки — `pantheon-seed-data`. Отвечаем в течение 14 дней.
- **Английский:** `README.en.md`, `CONTRIBUTING.en.md`, двуязычные формы.
- Установка без `gh`; «ставить только из upstream».

## v0.3.3 — 2026-10-14

- Рутина в планировщике Windows запускается через `pythonw` и вызывает git без консольных окон: ничего не мигает.
- Под планировщиком вывод и ошибки пишутся в `memory/routine.log` (локально, в git не уходит).
- `CLAUDE.md`: если отчёт старше суток (компьютер был выключен в час запуска), Claude сначала прогоняет рутину сам; ошибку из журнала показывает человеку.

## v0.3.0 — 2026-10-13

- `routine.py report` — сводные числа для формы в [pantheon-seed-data](https://github.com/alkanfel1987/pantheon-seed-data): версия, вызовы навыков, проблемы целостности, цикл обучения. Пути к домашней папке вычищаются. Отправляет человек.
- Подать навык можно формой «Навык для ядра» в том же репозитории.

## v0.2.0 — 2026-10-13

- **Рутина** `scripts/routine.py`: раз в день проверяет целостность навыков и скриптов, считает вызовы навыков по локальным журналам Claude Code, сводит цикл обучения и готовит новый релиз. Ничего не ставит и не отправляет сама: обновление — после «да» человека в начале сессии.
- Обновления идут только до релизов. Если ты правил файл, который меняет релиз, установка останавливается и называет файл.
- `CLAUDE.md`: шаг 0 — прочитать отчёт рутины.
