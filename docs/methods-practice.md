# Карта методов по болям

Здесь методы сгруппированы не по устройству, а по тому, что у тебя болит. Это выборка из рабочего реестра: только то, что запускалось на реальном материале, а не придумано за столом. Порядок переключения между пятью-шестью основными навыками — на соседней странице [methods-map.md](methods-map.md); здесь — широкий каталог практики с привязкой к боли.

**Как читать.** Строка: имя → вход → выход. *Прогонялся* — что записано в реестре о применении, без оценки качества. У большинства методов это один–три случая: такой метод — рабочая гипотеза, а не проверенная процедура. Если метод есть навыком в миниядре, стоит ссылка.

## 1. Мне принесли источник, и непонятно, кому верить

- **Пять вопросов к «X говорит Y»** → утверждение с источником → цвет по слабейшему ответу; недоступный источник — отдельный исход ⚪, не «нет». *Прогонялся:* как первый фильтр карантина и слой в source-filter. [pramana-panchaka](pramana-panchaka.md) · [source-filter](../.claude/skills/source-filter/SKILL.md)
- **Фильтр в три слоя** → выдача из нескольких источников → цепочка · ставка стороны · форма подачи → факт-ядро и список того, чего брать нельзя. *Прогонялся:* в работе. [source-filter](../.claude/skills/source-filter/SKILL.md)
- **Сверка с самим источником, а не с индексом** → намерение сослаться → прочитать файл, а не его описание → утверждение с названным ярусом чтения. *Прогонялся:* после случая, где ссылка была выдумана по краткому описанию.
- **Пересказчик страниц — тоже сторона** → страница прочитана инструментом, отдающим ответ малой модели → ярус «извлечено», звёздочка у чисел, сверка опорного числа вторым каналом. *Прогонялся:* три пойманных расхождения; частота искажений не измерена.
- **Карта финансирования** → поле исследований → кто оплатил кафедру, центр, испытание → узлы, которые нельзя цитировать как независимые. *Прогонялся:* один раз.
- **Работа, названная собеседником мимоходом** → найти, прочесть реферат, сверить статус (препринт или рецензирован) → записать ограничения самому. *Прогонялся:* один раз.
- **Проверка фактов статьи по фразам** → готовый текст → «удалить / переформулировать / оговорить / подтверждено», поиск записан, рядом «похожее, но другое». *Прогонялся:* один раз.
- **Фильтр выживших внутри одного источника** → авторитетная книга, часть тезисов которой не воспроизвелась → пятёрка по подтезисам, не итогом на книгу. *Прогонялся:* один источник.
- **Сайт не открывается** → страница отдаёт заглушку → идти в API того же источника; если не открывается всё — одновременная проба целевого и трёх контрольных узлов, чтобы отличить «недоступно» от «у меня сломано». *Прогонялся:* 4 раза подряд в одной линии работ; проба — один случай.

## 2. Я сам проверил свою разметку — и, конечно, всё сошлось

- **Слепая проверка** → своя классификация или сводка → предсказание с порогом записано и опечатано до прогона; читатель без моего контекста видит только материал → сравнение; провал предсказания — хороший исход, полное согласие подозрительно. *Прогонялся:* многократно в рабочем ядре автора; журналы в этот репозиторий не входят. [blind-check](../.claude/skills/blind-check/SKILL.md)
- **Серия печатей до чтения источника** → вопрос, ответ на который можно угадать из обучения → пронумерованные предсказания до чтения, исход по пунктам, арбитр — источник. *Прогонялся:* около пятидесяти пар «предсказание + исход». [blind-check](../.claude/skills/blind-check/SKILL.md)
- **Хотя бы одно маловероятное предсказание** → если все предсказания звучат «источник скажет обычное», ничего не взвешено → добавить то, что сам считаешь маловероятным. *Прогонялся:* одна сессия.
- **Проверка наводящести** → читатели единодушны по закрытым вариантам → тот же материал открытым вопросом; сместилось деление — оно рабочее огрубление, не природа. *Прогонялся:* десять закрытых разметок против пяти открытых.
- **Выборка, отобранная не автором** → закономерность найдена на самоотобранных примерах → машинный отбор по записанному правилу, автор видит только имена, предсказание опечатано, читатель независим. *Прогонялся:* один раз.
- **Положительный контроль измерителя** → нулевой результат → до чтения назвать случай, где совпадение известно; нуль засчитывается только если измеритель его находит. *Прогонялся:* три случая.
- **Прочитать готовый артефакт целиком** → тесты зелёные → тесты проверяют наличие полей, а не вид и читаемость. *Прогонялся:* три случая за одну сессию.

## 3. Мне назвали красивое число

- **Число считает код, а не модель** → модель должна выдать частоту → пусть вернёт перечень, а считает код → число из счёта, не оценка на глаз. *Прогонялся:* один случай.
- **Расхождение двух чисел** → два числа об одном предмете → развести, что считает каждый счётчик; «красивую арифметику под известную сумму» назвать подгонкой → таблица «установлено / не установлено». *Прогонялся:* один случай; подгонка опровергнута прямым опросом всех записей.
- **Трассировка цитируемого числа** → число без ссылки в нескольких документах → найти протокол, границу знаменателя, пересчитать. *Прогонялся:* один раз.
- **Происхождение чисел итога** → итог + источники → воспроизвести прогон, сверить хеши, пересчитать арифметику, таблица «число → источник → вердикт». *Прогонялся:* один раз.
- **Охват формулировки** → «число верно» отдельно от «при каких условиях держится» → OK / УЖАТЬ. *Прогонялся:* один раз.
- **Переносимость измеренного** → число получено на одном объекте и предлагается для другого → не принимать совпадение главного параметра за сопоставимость; сверить стадию, среду, показатель, режим. *Прогонялся:* три раза.
- **Малая проба показывает лучший случай** → «источник сам обезличивает» → решение только после пробы из пятидесяти и больше. *Прогонялся:* замер на такой пробе показал утечки там, где на малой их не было видно.
- **Заявление не сильнее доказательства** → утверждение перед встраиванием → пять рангов вероятностных слов вместо цветов. *Прогонялся:* как фильтр карантина. [quarantine](quarantine.md)

## 4. Нашёл закономерность — а не случайность ли

- **Нулевая модель для признаков** → гипотеза о следе во фразе → признаки заданы до расчёта, фон из сопоставимых предложений, порог с поправкой на число признаков. *Прогонялся:* замер на одном корпусе.
- **Фон случайных перестановок** → гипотеза о сохранении порядка → мера против тысячи перемешиваний. *Прогонялся:* замер; гипотеза не отличилась от фона.
- **Контроль случайными параметрами** → довод «работают именно эти числа» → те же меры с параметрами наугад. *Прогонялся:* два раза.
- **Нулевая модель среза** → признак мерится по набору объектов на каждую дату → полоса шума строится перестановкой приписки признаков внутри даты. *Прогонялся:* один раз.
- **Устойчивость победителя к границе выборки** → гейт «интервал выше нуля» → пересчёт на нескольких границах деления; правило с интервалом выше нуля в одном окне и с обратным знаком в другом — вот цена отметки «выше нуля». *Прогонялся:* три правила на четырёх окнах.
- **Ошибка среднего по блокам времени** → разброс между объектами, делённый на корень из их числа, верен только для независимых → три способа дали три ответа о числе независимых. *Прогонялся:* один раз.
- **Удержание вместо поправки** → две версии объяснения скачка → проверять неизменным составом, а не поправкой. *Прогонялся:* две версии, фальсификатор записан до замера.

## 5. Измеритель молчит или врёт

- **Вырожденный результат** → «0 из N» или «N из N» → сначала подозрение на измеритель, не на предмет: сверить одну позицию вручную. *Прогонялся:* введён после повторяющегося класса сбоев; ложные срабатывания учтены.
- **Матчер на старом формате** → критерий исчерпания фазы извлечения → два затвора и проверка самого счётчика на формате прежней версии. *Прогонялся:* дефект шаблона найден при применении.
- **Инварианты в расчётном скрипте** → расчёт баланса → эталонная точка, замыкание баланса, запрет «больше входа»; сборка падает при нарушении. *Прогонялся:* первая версия провалила собственную проверку и была исправлена.
- **Тест причинности показателей** → ряд во времени → значение в точке i из полных данных равно значению из ряда, обрезанного до i. *Прогонялся:* на реальных данных, все показатели набора.
- **Прогон на живом входе** → тесты зелёные → сценарий из тех же кирпичей, но так, как пишет пользователь, или тот же модуль на живых данных. *Прогонялся:* 6 случаев в шести сессиях, в каждом найден дефект, которого не ловили тесты.
- **Живость по первичному полю** → «работает ли рутина» → не по косвенным признакам (дата правки, тишина в чате), а по времени последнего запуска и коду возврата; «не вижу» ≠ «нет». *Прогонялся:* три раза.

## 6. Ошибка повторяется, фикс не держится

- **Послойный спуск + четыре ракурса** → повторяющаяся ошибка в многослойной системе → снять слой, исправить, проверить, нырнуть глубже до основания, затем осмотреть основание с разных сторон. *Прогонялся:* в работе. [deep-debug-loop](../.claude/skills/deep-debug-loop/SKILL.md)
- **Починка на месте** → баг найден сейчас → тривиальный чиню, нетривиальный в спуск; обязательный прогон проверки; тег в трассу. [fix-on-sight](../.claude/skills/fix-on-sight/SKILL.md)
- **Промоция повторов** → один класс ошибки три раза → правка навыка или правила, а не очередная заплатка. *Прогонялся:* журнал из нескольких промоций. [promote-pattern](../.claude/skills/promote-pattern/SKILL.md)
- **Источник регенерирует файл** → файл — производное → до записи определить, какой слой источник; прогон туда-обратно; направление синхронизации. *Прогонялся:* 5 случаев в пяти сессиях.
- **Сверка прошлых утверждений по транскриптам** → «в другой сессии ты говорил обратное» → не соглашаться и не спорить, найти и прочитать ту сессию. *Прогонялся:* один случай.

## 7. Мой вывод держится на том, чего нет

- **Отрицательное утверждение требует записанного поиска** → «не найдено» → под каждым выводом перечень поисков: запросы, где искал, что нашлось рядом. *Прогонялся:* в инвентарных прогонах и публикациях.
- **Отсутствие как свидетельство** → термин приписан школе → посчитать, где он встречается по слоям корпуса: нет в коренных текстах, густо в поздних — он принадлежит слою, не школе. *Прогонялся:* один случай.
- **Голос другой стороны** → все источники принадлежат победителю → ядро версии собеседника одной фразой, четыре объяснения молчания и чем они различаются. *Прогонялся:* первый прогон, одиннадцать пунктов. [other-side-voice](../.claude/skills/other-side-voice/SKILL.md)
- **Гипотеза «скрыли» через незаинтересованную сторону** → «странность» в документах → развести даты, проверить перевёрнутую причинность, найти свидетеля против своего интереса. *Прогонялся:* один раз, на трёх «швах».
- **Довод «редкое теряется»** → накопительная кривая первых записей по датированным памятникам плюс счёт по бытовому корпусу. *Прогонялся:* один раз; одна из оценок, вероятно, завышена ограничением корпуса.

## 8. Надо решить, а не просто узнать

- **Развилка** → два и более взаимоисключающих варианта → проверка устаревших допущений, не порождены ли варианты одной парадигмой, прогноз по каждому. *Прогонялся:* в работе. [simulate-fork](../.claude/skills/simulate-fork/SKILL.md)
- **Конкурирующие гипотезы** → спор, дорогая ошибка → перечислить, включая скучную; взвешивать диагностичностью свидетельства. *Прогонялся:* в работе. [ach-pramana-analysis](../.claude/skills/ach-pramana-analysis/SKILL.md)
- **Предсмертный разбор** → решение «встроить» → представить провал и назвать причину до исхода. *Прогонялся:* шаг исхода карантина. [quarantine](quarantine.md)
- **Разведка проходимости** → замысел, источник, площадка → живые пробники по шести осям до вложения сил. *Прогонялся:* два проверочных случая. [kshetra](../.claude/skills/kshetra/SKILL.md)
- **Матрица «кандидат × критерий»** → выбор по данным → у каждой клетки источник и дата, «не измерено» вместо оценки, поправка к собственному прошлому прогону. *Прогонялся:* два прогона.
- **Шкала 0–2 с проверкой устойчивости порядка** → ранжирование вариантов → данные отдельно от оценки; удвоить вес одного критерия и посмотреть, меняется ли состав первой группы. *Прогонялся:* один раз, без слепой проверки.
- **Порядок величины с названным методом** → величины нет в источниках → метка [оценка], арифметика допущений, вилка. *Прогонялся:* две оценки; калибровки нет.

## 9. Чужой инструмент обещает много

- **Аудит перед установкой** → расширение, сервер или набор навыков → в карантин, состав смотреть по самому репозиторию, читать каждое утверждение с путём и строкой. *Прогонялся:* 2 раза.
- **Разбор агентного репозитория по коду** → заявленные возможности → что внутри (проверено по коду) отдельно от маркетинга, которого в коде нет. *Прогонялся:* один репозиторий.
- **Оценка инструмента экономии** → заявка продавца → независимый замер, базовая линия до установки, внедрять по одному с замером. *Прогонялся:* четыре инструмента: два приняты, один отклонён по замеру.
- **Триаж находок сканера** → отчёт статического сканера → корзины по смыслу: сознательный выбор · ложное срабатывание · чужой файл · править. *Прогонялся:* один раз с повторным сканом.

## 10. Память, сессии, письма

- **Память — точка во времени** → путь или функция из памяти → проверить до рекомендации; устаревшее обновить. *Применяется* как постоянное правило.
- **Передача между сессиями** → закрытие при незавершённой работе → живой статус, снимок, пять разделов. *Прогонялся:* регулярно; качество передачи не измерено.
- **Не писать «я прочитал» без подтверждения** → письмо получателю → мягкая формулировка или «читал только вторичные источники». *Прогонялся:* на прецедентах.
- **Не выводить личное из ника или почты** → нужен факт о человеке → нет в подтверждённом источнике — спросить. *Прогонялся:* один прецедент.
- **Проверка рассылки таблицей** → черновики писем → «утверждение · источник · статус» с воротами отправки. *Прогонялся:* шесть писем.

## Что эта карта не говорит

- Реестр размечал сам автор методов; независимого аудита нет. «Прогонялся» — запись о запуске, не оценка полезности.
- Метод с одним случаем — гипотеза. Где полезность не измерена, так и сказано.
- Страница не заменяет [methods-map.md](methods-map.md): та говорит, в каком порядке переключаться между методами, эта — где искать метод под свою боль.
