# Карта методов работы с информацией

Одна страница вместо слияния нескольких навыков в один. Замер показал: слияние навыков семейства в один не окупается ни по токенам (экономия порядка 900 токенов на ход, расход на вызове выше примерно на 1,5 тыс.), ни по скорости; окупается только устранение противоречий между ними. Их два: **три шкалы ярусов под одним словом** и **отсутствие порядка переключения между методами**. Эта страница закрывает оба. Файлы навыков остаются и ссылаются сюда.

## 1. Две оси, не одна

Слово «ярус» обозначало три разные вещи. Теперь — две оси, и у утверждения **обе метки**.

| Ось | Что меряет | Шкала | Где живёт |
|---|---|---|---|
| **Цепочка** | кто и как это сказал: locus · свидетели · оригинал · без обобщения · неоднозначность | 🟢 мейнстрим / первоисточник · 🟡 легитимно, вторично · 🟠 фриндж / один источник / источник со ставкой · 🔴 нет цепочки | [pramana-panchaka.md](pramana-panchaka.md) §2–3 |
| **Измеренность** | есть ли число: N, эффект, интервал | Tier-1 измерено · Tier-2 наблюдаемо или описано в трактатах, но не измерено · Tier-3 нарратив без коррелята | [evidence-stratify](../.claude/skills/evidence-stratify/SKILL.md) |

Соответствие старых шкал: ярусы 1/2/3 в ACH → 🟢/🟡/🟠–🔴 (ось цепочки). «Ярус-1» в рабочих заметках («первоисточник прочитан целиком») = 🟢 по цепочке; про измеренность это ничего не говорит.

Нормальный случай — «🟢 · Tier-2»: реферат открыт, эффект не измерен. Опасный — «🟠 · Tier-1»: число есть, но от стороны со ставкой (пресс-релиз с процентом).

## 2. Три модели и чем они различаются

| | Следствие | Ракурсы | Слои |
|---|---|---|---|
| **Вопрос** | что из этого верно? | что я не увидел? | почему это так? |
| **Единица** | утверждение | точка зрения / субъект вопроса | причина |
| **Движение** | отбор гипотез через несовместимость со свидетельством | вокруг объекта, смена рамки | вниз, к основанию |
| **Порождает** | ничего — только отбирает среди названного | новые гипотезы и слои | следующий слой |
| **Остановка** | гипотезы разведены или объявлены неразличимыми | **своей нет** — критик полноты всегда найдёт ещё | основание: ниже нет слоя, меняющего вывод |
| **Реакция на отсутствие данных** | отсутствие свидетельства ≠ свидетельство отсутствия; но не найденный *предсказанный* след — улика | «не туда смотришь» — сменить субъект | «не тот слой» — нырять |
| **Типичная ошибка** | ложная атрибуция, сводка вместо источника | вердикт шире охвата | починен симптом |
| **Навыки** | [verification-first](../.claude/skills/verification-first/SKILL.md), [ach-pramana-analysis](../.claude/skills/ach-pramana-analysis/SKILL.md), [evidence-stratify](../.claude/skills/evidence-stratify/SKILL.md), [source-filter](../.claude/skills/source-filter/SKILL.md), [blind-check](../.claude/skills/blind-check/SKILL.md) | [deep-debug-loop](../.claude/skills/deep-debug-loop/SKILL.md), механика 3 | [deep-debug-loop](../.claude/skills/deep-debug-loop/SKILL.md), вертикаль |

Общего критерия остановки не построить — он у каждой модели свой, и это суть различия, а не дефект. Поэтому не слияние, а порядок.

## 3. Порядок и переключение

```
ядро одной фразой → ракурсы (породить) → следствие (отобрать) → слои (объяснить оставшуюся)
       ↑                                                                    │
       └──────────────── ракурсы на найденном слое ←────────────────────────┘
```

**Правила переключения:**
- **Три опровержения звеньев подряд** → не четвёртое звено, а ракурсы. Гипотезы кончились, нужен генератор. (Пример из практики: пятнадцать ходов следствия не дали ничего, один проход ракурсов дал лучшего кандидата за день.)
- **Основание найдено** → ракурсы на нём до объявления (механика 3 в [deep-debug-loop](../.claude/skills/deep-debug-loop/SKILL.md)).
- **Довод опирается на отсутствие** (нет записей, нет следов) → [other-side-voice](../.claude/skills/other-side-voice/SKILL.md) до любого вывода.
- **Источник с видимой стороной** → [source-filter](../.claude/skills/source-filter/SKILL.md) до опоры на него.
- **Своя разметка или классификация перед публикацией** → [blind-check](../.claude/skills/blind-check/SKILL.md).
- **Результат идёт в канон вашей базы знаний** → [quarantine](quarantine.md): это ворота, а не метод рассуждения.
- **Знание исчерпано, а решать надо** (противник противодействует · среда не даёт обратной связи · хвост распределения не измерен) → методы этой карты здесь кончаются: вопрос «что верно» сменяется вопросом «чем решать вместо знания». Не продолжайте искать истину там, где её добыть нельзя; назовите, какой из этих трёх случаев перед вами, и выбирайте правило решения под него, а не ещё одну проверку фактов.

## 4. Маршрутизатор: тип входа → процедура

| Вход | Процедура | Файл |
|---|---|---|
| одно внешнее утверждение | открыть источник и прочитать его, пятёрка вопросов | [pramana-panchaka.md](pramana-panchaka.md) |
| выдача из нескольких источников | цепочка → ставка → искажение → факт-ядро | [source-filter](../.claude/skills/source-filter/SKILL.md) |
| спор гипотез, дорогая ошибка | ACH: перечислить, диагностичность, отбор устранением | [ach-pramana-analysis](../.claude/skills/ach-pramana-analysis/SKILL.md) |
| серия утверждений / синтез | две оси + фальсификатор моста | [evidence-stratify](../.claude/skills/evidence-stratify/SKILL.md) |
| одна сторона молчит | четыре объяснения молчания, примета письма | [other-side-voice](../.claude/skills/other-side-voice/SKILL.md) |
| своя классификация | слепая проверка под-агентом | [blind-check](../.claude/skills/blind-check/SKILL.md) |
| ошибка повторяется, система многослойная | вертикаль + горизонталь | [deep-debug-loop](../.claude/skills/deep-debug-loop/SKILL.md) |
| встраивание в базу знаний | фильтр 7+1 | [quarantine.md](quarantine.md) |
| знания не будет, решать надо | различить, какой из трёх случаев (противник · нет обратной связи · неизмеренный хвост), и назвать отказ выбранного правила решения | см. последнее правило §3 |

## 5. Общие предохранители (действуют во всех процедурах)

1. **Слой 0 — инструмент доставки.** Сводка поиска и пересказчик страницы — тоже сторона: они оптимизируют связность, а не точность. Факт берётся из полного текста; цитата — только из увиденного. Примеры: пересказчик перевернул направление эффекта в исследовании; пересказчик выдал цитаты из книги, которых в ней нет.
2. **Ставка ≠ ложь.** Заинтересованность говорит, где искать искажение, а не есть ли оно. Отбросить источник за интерес — генетическая ошибка; «независимый» часто значит «не в теме».
3. **Элегантность = сигнал риска**, а не подтверждения (см. [evidence-stratify](../.claude/skills/evidence-stratify/SKILL.md)): гладкий синтез из многих кусков чаще красив, чем верен.
4. **Ядро версии собеседника — одной фразой, сверить**, и только потом разбирать звенья. Разбор звеньев чужой версии, ядро которой понято неверно, опровергает не то.
5. **«По памяти» — метить ⚠️ в выводе**, снимать метку только после сверки с источником. (На первом прогоне other-side-voice из 11 пунктов, поданных по памяти, 8 подтвердились, 3 — с оговорками.)

## 6. Фальсификатор страницы

Слияние навыков отложено. Сливать, если в следующих **пяти** применениях семейства: (а) дважды взят не тот навык, или (б) выданы противоречивые метки на одном материале. Если за пять применений ни того ни другого — страница работает, слияние не нужно. Если правило «три опровержения → ракурсы» ни разу не сработало раньше, чем на него указал человек, за три исследовательские линии — §3 декоративен: переносить в механическую проверку или снимать.
