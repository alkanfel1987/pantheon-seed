# evidence-stratify — стратификация по доказательности

Закрывает recurring-задачу: пользователь приносит серию синтезов (часто бот-сгенерированных) о сознании / эпигенетике / практиках / любой пограничной теме, и нужно **не принять и не отвергнуть оптом**, а разложить по уровню доказательности. Прецедент: сессия 2026-06-01 (эпигенетика, контемплативная физиология, survival-трек).

Параллельно реализует анти-само-синтез урок той же сессии: к **своему** выводу применять тот же фильтр, что к входящему. «Дух=давление=один акт» — элегантная унификация, выданная без фильтра, поймана пользователем как Malleus-проекция (этическое выдано за эмическое). **Элегантность = сигнал риска, не подтверждения.**

## Когда срабатывает

- Пользователь явно вызвал `/evidence-stratify`
- «разберись что из этого реально / доказано», «стратифицируй», «разложи по доказательности», «что измерено а что нет»
- Пользователь скармливает ≥2 связанных claim'а / абзацев синтеза для разбора
- Перед публикацией **собственного** синтеза, объединяющего несколько источников в красивую связную историю (self-check)

**НЕ срабатывает:**
- Решение integrate/archive/purge для основного vault → `/quarantine`
- Одиночный внешний факт без серии → `verification-first` + WebSearch
- Личные наблюдения пользователя (не внешние утверждения)

## Трёхслойная схема (главная абстракция)

Каждое утверждение раскладывается по ДВУМ осям.

> **Две оси, не одна (уточнение 2026-09-12).** Tier здесь — ось **измеренности** (есть ли число). Ось **цепочки до источника** (кто и как сказал) — отдельная, цвета 🟢🟡🟠🔴 из `<корень миниядра>/docs/pramana-panchaka.md` §3; ACH и source-filter работают по ней. Утверждение получает обе метки: «🟢 по цепочке, Tier-2 по измерению» — нормальный случай (первоисточник прочитан, эффект не измерен). Карта осей и методов: `<корень миниядра>/docs/methods-map.md`.

### Ось A — Tier доказательности

- **Tier-1 · Измеренное.** Есть peer-reviewed измерение с числами / эффектом / N / PMID. Пример: мелатонин при медитации (Tooley 2000), β-эндорфин (Yadav 2012). Маркировать источник + число.
- **Tier-2 · Наблюдаемо-но-не-измерено / в трактатах.** Механизм правдоподобен, описан в первоисточнике или клинически наблюдаем, но прямого измерения эффекта нет. **Это белые пятна — фальсифицируемые.** Пример: кечари→нейропептиды, випарита-карани (механизмы реальны, эффект не измерен).
- **Tier-3 · Спекуляция / текст-как-текст.** Только нарратив, трактатное утверждение без наблюдаемого коррелята, или мост между доменами без основания. Пример: амрита как буквальная субстанция, краниосакральный «ритм» (= псевдонаука, флаг).

### Ось B — Эпистемический статус (для каждого «моста»/связки)

- **НАБЛЮДЕНИЕ** — что зафиксировано (нейтрально, до интерпретации).
- **ИНТЕРПРЕТАЦИИ (конкурирующие)** — ≥2 объясняющие рамки, без выбора «правильной» оптом.
- **МОСТ (F6-gated)** — связка между регистрами/доменами. **Требует named-фальсификатора:** что должно быть обнаружено, чтобы мост рухнул. Нет фальсификатора → мост = Tier-3.

**Эмическое ≠ этическое.** Явно метить: это сводка изнутри носителей традиции (эмическое) или внешняя аналитическая рамка (этическое)? Склейка = ошибка Malleus-класса.

## Workflow

### Шаг 1 · Разбить на атомарные claim'ы

Серию синтеза декомпозировать на отдельные проверяемые утверждения. Один абзац = часто 3-5 claim'ов разного tier. Не стратифицировать абзац целиком — он смешанный.

### Шаг 2 · Источник-верификация (читать источник до утверждения о нём, до разметки)

Для каждого Tier-1-кандидата **открыть источник** перед тем как поверить атрибуции. Бот-синтезы регулярно дают неверные атрибуции (прецедент 2026-06-01: Klengel/Bohacek перепутаны, Херберт→на деле Tooley, «×10 глимфатика»→~2×). WebSearch / WebFetch / PMID. Не нашёл (paywall/403) → пометить пробел, не повышать tier на доверии.

### Шаг 3 · Разметить по обеим осям

Вывести таблицу (см. формат ниже). Для каждого claim: Tier (A) + статус (B) + источник/число + named-фальсификатор (если мост).

### Шаг 4 · Само-фильтр (если разбираю свой синтез)

Перед выводом собственной объединяющей формулировки прогнать:
- Это эмическое или этическое? Не выдаю ли аналитическую сводку за единство изнутри?
- Назвать фальсификатор моей унификации. Не могу назвать → это Tier-3, переформулировать как гипотезу.
- Красиво/элегантно сходится? → флаг риска, перепроверить, не поддаться.

### Шаг 5 · Вывод + handoff

- Сводная таблица tier-разметки.
- Отдельной секцией — **белые пятна Tier-2** (фальсифицируемые, кандидаты на будущий замер).
- Отдельной секцией — **Tier-3 с флагами** (что отвергнуто и почему).
- Если результат идёт в канон (yaml/_Библиотека) — это уже зона `/quarantine`, передать туда; evidence-stratify готовит разметку, не канонизирует сам.

## Формат вывода

```
## Стратификация: <тема серии>

| # | Claim (атомарный) | Tier | Статус (B) | Источник / число | Фальсификатор (если мост) |
|---|---|---|---|---|---|
| 1 | ... | 1 измерено | НАБЛЮДЕНИЕ | Tooley 2000, мелатонин ↑ | — |
| 2 | ... | 2 не измерено | МОСТ | трактат X | измерить нейропептид Y |
| 3 | ... | 3 спекуляция | МОСТ без фальс. | — | ❌ нефальсифицируемо |

**Белые пятна (Tier-2, фальсифицируемые):** ...
**Отвергнуто (Tier-3 + флаг):** ...
**Эмическое/этическое:** где склейка устранена.
**Пробелы источников:** что не удалось верифицировать (paywall/403).
```

## Антипаттерны

- ❌ Стратифицировать абзац целиком — он смешанный, декомпозировать на атомы
- ❌ Доверять атрибуции бот-синтеза без открытия источника
- ❌ Принимать/отвергать серию оптом — теряется весь смысл
- ❌ Мост без named-фальсификатора, оставленный как Tier-2 — это Tier-3
- ❌ Своя элегантная унификация без само-фильтра — Malleus-класс (прецедент 2026-06-01)
- ❌ Склейка эмического и этического — выдать «изнутри традиции» за аналитический вывод
- ❌ Канонизировать прямо здесь — это работа `/quarantine`

## Связь с другими skills

- **quarantine** — после стратификации, если Tier-1/2 идёт в основной vault
- **verification-first** — Шаг 2 источник-верификация ↔ verification-first plan
- **simulate-fork** — если разметка вскрывает mutually-exclusive интерпретации с последствиями
